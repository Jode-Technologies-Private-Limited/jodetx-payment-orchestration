Create a payment transaction across UPI, Net Banking, Credit Card, or Debit Card.

## Endpoint

```http
POST /payment/initiate
```

## Checksum Formula

```text
mid|orderNo|rrn|txnAmount|paymentMode|paymentCode|salt
```

## Supported Payment Modes

| Payment Method | `paymentMode` | `paymentCode` |
| --- | --- | --- |
| UPI Collect | `UPI` | `UPII` |
| UPI Intent | `UPI` | `UPIC` |
| Dynamic QR | `UPI` | `DQR` |
| Net Banking | `NB` | Bank code, for example `HDFC` |
| Credit Card | `CC` | `CC` |
| Debit Card | `DC` | `DC` |

## Common Request Fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `mid` | string | Yes | Merchant ID |
| `orderNo` | string | Yes | Unique merchant order number |
| `rrn` | string | Yes | Retrieval reference number generated by merchant or gateway integration layer |
| `txnAmount` | string | Yes | Transaction amount as decimal string |
| `paymentMode` | string | Yes | Payment mode |
| `paymentCode` | string | Yes | Payment code for selected mode |
| `customerName` | string | Conditional | Customer name |
| `customerMobile` | string | Conditional | Customer mobile number |
| `customerEmail` | string | Conditional | Customer email address |
| `returnUrl` | string | Conditional | Browser return URL for redirect flows |

## Success / Pending Response

```json
{
  "txnId": "TXN123456789",
  "rrn": "RRN123456789",
  "orderNo": "ORD-20260529-0001",
  "paymentMode": "UPI",
  "paymentCode": "UPII",
  "redirectUrl": null,
  "qrString": null,
  "response": {
    "status": "PENDING",
    "statusCode": "200",
    "message": "Transaction initiated"
  }
}
```

## cURL

```bash
curl -X POST https://<uat-host>:8085/s2s/v1/payment/initiate \
  -H "Content-Type: application/json" \
  -H "X-Merchant-Id: B10001" \
  -H "X-Checksum: <checksum>" \
  -d '{"encryptedData":"<encrypted-payload>"}'
```

## Error Scenarios

| Scenario | HTTP Code | Resolution |
| --- | --- | --- |
| Unsupported payment mode | `400` | Use one of `UPI`, `NB`, `CC`, `DC` |
| Invalid amount | `400` | Send amount as a positive decimal string |
| Invalid checksum | `401` | Use the Initiate Transaction checksum formula |
| Downstream timeout | `500` | Query Transaction Status before retrying |
